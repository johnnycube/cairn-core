# 1. Record architecture decisions

Status: accepted

## Context

Cairn's structural choices (layering, packaging, code generation) were documented only in prose
spread across README.md and docs/architecture.md, which drifts.

## Decision

Significant architecture decisions are recorded here as numbered ADRs (context, decision,
consequences). An ADR is never rewritten after acceptance; a later ADR supersedes it.

## Consequences

New structural changes come with an ADR in the same pull request. ADRs 0002–0004 record decisions
that predate this log.
